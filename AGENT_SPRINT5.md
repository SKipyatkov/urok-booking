## Контекст

MVP работает, **14 тестов проходят**. Спринт 4 добавил визуальный polish — **заказчику не понравилось**.

Проблемы текущего UI (спринт 4), которые нужно убрать:
- Фиолетово-индиго градиенты («ещё один SaaS-стартап»)
- Пёстрый auth-экран с логотипом-буквой «У» на градиенте
- Избыточные тени, бейджи, «конфетность» без пользы
- Ощущение шаблонного лендинга, а не спокойного инструмента для репетиторов и родителей

**Задача спринта 5:** переделать **только визуал и вёрстку**, не ломая логику и тесты.

## Новое направление дизайна (обязательно)

**Стиль:** спокойный, доверительный, «инструмент для записи на уроки», не маркетинговый лендинг.

| Принцип | Как |
|--------|-----|
| Цвета | Нейтральный фон + **один** спокойный акцент (например тёплый синий `#2563eb` или зелёно-синий `#0d9488`). **Без градиентов** на фоне страниц |
| Auth | Белый/светло-серый фон, простая карточка по центру, без логотипа-кружка и без fullscreen-gradient |
| Публичная запись | Чистая страница: название школы → дата → слоты → форма. Без «Шаг 1/2/3» капсом, без бейджа «бесплатно». Достаточно понятных заголовков |
| Кабинет | Лаконичная шапка, много воздуха, акцент на календаре и ссылке для родителей |
| Ошибки 404/500 | Минималистично, без огромных gradient-текстов «404» |
| Типографика | Системный шрифт, нормальные размеры, без uppercase-лейблов |
| Мобилка | Приоритет — родитель записывает с телефона |

Ориентиры по ощущению (не копировать 1:1): Calendly, YClients lite, Notion forms — **просто и по делу**.
