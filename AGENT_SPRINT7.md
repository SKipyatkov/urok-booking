# Промпт — Спринт 7 (Фичи для пилотов)

Проект: `/home/kipyatoook/urok-booking`. Спринт 6 должен быть готов (prod basics).

## Цель

Добавить фичи, которые репетитор **увидит сразу** при пилоте.

## Фичи (все обязательны в этом спринте)

### 1. Статистика на дашборде `/cabinet/`

Карточки-счётчики (по organization):
- **Новые** ученики (`Student.status=new`)
- **Ожидают** подтверждения (`Booking.status=pending`)
- **На пробном** (`Student.status=trial` или trial bookings на неделе)
- **Учатся** (`Student.status=active`)

Компактный блок над календарём. Без графиков — только цифры.

### 2. Лендинг на `/` для гостей

Сейчас `/` редиректит на login. Изменить:
- **Не авторизован** → лендинг: что такое Urok, для репетиторов/школ, CTA «Регистрация» / «Войти», логотип
- **Авторизован** → редирект в `/cabinet/` как сейчас

Шаблон: `templates/landing.html`. Стиль — текущая тёмная тема, без маркетингового пафоса.

### 3. Экспорт CSV

- `/cabinet/students/export/` — CSV учеников (имя ребёнка, родитель, email, телефон, статус, дата)
- `/cabinet/bookings/export/` — CSV бронирований (дата, ученик, статус, тип, meeting_url)
- Только для авторизованного преподавателя своей organization
- Кнопки «Скачать CSV» на страницах students и bookings

### 4. Редактирование slug в настройках

- В `OrganizationSettingsForm` добавить поле `slug` (с валидацией: латиница, цифры, дефис)
- Проверка уникальности
- При смене slug — предупреждение «старая ссылка перестанет работать»
- Обновить публичную ссылку на дашборде после сохранения

## Технические требования

- Django templates + текущий `app.css`
- Тесты на каждую фичу (минимум 4 новых теста)
- Все старые тесты зелёные

## Не делать в этом спринте

- Email-напоминания (спринт 8)
- ЮKassa (спринт 9)
- Celery, Redis

## Готово когда

- 18+ тестов OK
- Лендинг открывается без логина
- CSV скачивается
- Slug меняется в настройках
- Дашборд показывает 4 счётчика

Начинай со статистики на дашборде, затем лендинг.
